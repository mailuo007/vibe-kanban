## Current status

- The project direction is to embed Feishu support directly into `crates/server`.
- The selected model is a global Feishu bot pool with workspace-level bindings.
- The core implementation is now in the codebase, including direct inbound chat commands over Feishu long connection mode, ordinary message routing into one fixed workspace session per Feishu chat, receive-ack reactions on inbound group messages, event-driven group announcement status sync, late-summary-safe reply delivery back to the same bound chat, and session refresh in the workspace UI without a full page reload.
- The remaining work is limited to live credential validation and any future product refinements such as richer progress streaming.
